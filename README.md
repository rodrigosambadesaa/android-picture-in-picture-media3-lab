# Android Picture-in-Picture + Media3 Lab

A compact reimplementation showing Media3/ExoPlayer playback inside an activity that supports Android Picture-in-Picture (PiP).

It demonstrates manifest PiP configuration, explicit PiP entry, automatic entry on Android 12+, aspect ratio configuration, and hiding non-video controls while in PiP.

The sample streams Google's public ExoPlayer test media and therefore needs Internet access.
