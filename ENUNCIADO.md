# Enunciado didáctico reconstruido — Picture-in-Picture con Media3

Laboratorio Android para reproducir vídeo mediante Media3/ExoPlayer dentro de una Activity compatible con **Picture-in-Picture (PiP)**.

La aplicación debe:

- configurar en el `AndroidManifest` la compatibilidad con PiP;
- reproducir un vídeo con Media3/ExoPlayer;
- permitir la entrada explícita en modo PiP;
- aprovechar la entrada automática en versiones Android que lo soportan;
- establecer una relación de aspecto adecuada para la ventana PiP;
- ocultar los controles no esenciales cuando la Activity se encuentra en PiP;
- restaurar la interfaz normal al regresar a pantalla completa.

El ejemplo utiliza contenido de prueba remoto y, por tanto, requiere conexión a Internet para la reproducción por defecto.

No existe una base de datos asociada.
